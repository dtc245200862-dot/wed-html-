HUY.DEV - Website Portfolio Cá nhân



Giới thiệu



Đây là website portfolio cá nhân được xây dựng trong quá trình học phát triển web.



Website giới thiệu thông tin cá nhân, kỹ năng, các dự án đã thực hiện và thông tin liên hệ.



Các trang



\- Trang chủ

\- Giới thiệu

\- Dự án

\- Liên hệ



Công nghệ sử dụng



\- HTML5

\- CSS3

\- Flexbox

\- CSS Grid

\- Responsive Web Design



Chức năng



\- Sử dụng cấu trúc HTML5 semantic

\- Giao diện responsive

\- Thiết kế theo hướng Mobile First

\- Điều hướng giữa các trang

\- Hiển thị các thẻ dự án

\- Biểu mẫu liên hệ

\- Hiệu ứng hover

\- Hỗ trợ màn hình điện thoại, máy tính bảng và máy tính
